# 禾安的笔记 · HeAn

> **AI 时代的独立开发者** —— 分享 iOS 移动端开发、技术选型与独立开发的思考。

🌐 **在线访问：<https://www.hacore.cn/>**

---

## 这是什么

一个个人展示与技术分享网站，包含：

| 板块 | 内容 |
|---|---|
| **首页** | 精选专题 · 精选项目 · 最新博文 |
| **专题** | 成体系的技术教程（如《iOS 开发：从 0 到上架》）|
| **博客** | 技术随笔与独立开发记录 |
| **项目作品** | 自己做的小工具与产品 |
| **关于我** | 个人介绍与联系方式 |

## 技术栈

- **HTML5 + Tailwind CSS**（CDN 引入，**无需构建** ✓）
- **原生 JavaScript**（模块化，**无框架** ✓）
- 没有打包、没有编译 —— 克隆下来用任意静态服务器即可预览 ✓

## 目录结构

```
index.html                              首页
about/  blog/  topics/  projects/       各板块页面
js/                                     JavaScript 模块（渲染 / SEO / 主题 / 请求）
assets/                                 图片、字体等静态资源
data/                                   离线兜底用的初始数据
robots.txt  sitemap.xml                 搜索引擎相关
```

## 本地预览

项目是纯静态的，任意静态服务器都可以：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080/
```

> 部分数据来自接口；接口不可用时会自动降级为本地缓存 / 内置初始数据 ✓

## 一些实现细节

- **双层降级**：优先取接口数据 → 失败则读本地缓存 → 再失败回落内置初始数据 ✓ 保证站点始终可访问 ✓
- **暗黑模式**、**响应式**（移动端 / 平板 / 桌面 ✓）
- **图片懒加载** + 默认占位图 ✓
- **SEO**：语义化 meta、`robots.txt`、`sitemap.xml` ✓
