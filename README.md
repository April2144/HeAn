# HeAn - 禾安个人展示网站

面向用户的纯静态个人展示网站，展示项目作品、技术博客、个人简介等信息。采用 HTML + JS + Tailwind CSS 构建，无需构建工具。

## 页面结构

| 页面 | 说明 |
|------|------|
| 首页 | Hero + 关于我 + 精选项目 + 最新博文 + 联系 |
| 关于我 | 个人详细介绍 |
| 项目作品 | 项目列表 + 详情页 |
| 博客 | 博客列表 + 文章详情页（含章节导航） |
| 联系合作 | 联系表单 / 公众号引流 |

## 技术特点

### 双层降级数据加载
- 优先从后端 API 获取实时数据
- 后端不可用时自动降级读取本地 JSON，保证站点始终可访问

### 功能特性
- 暗黑模式切换
- 响应式设计（适配移动端/平板/桌面）
- 博客详情页章节导航（上一篇/下一篇）
- 项目分组展示
- Newsletter 订阅
- 系统标签徽章（分组标识 + 图标）
- 图片懒加载 + 默认占位图
- SEO 友好的 meta 标签

## 技术栈

- HTML5 + Tailwind CSS
- 原生 JavaScript（模块化）
- 无框架、无构建工具
